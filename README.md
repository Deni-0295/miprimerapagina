# My First Web Page — HTML & CSS

## Español

### Descripción del proyecto

Este proyecto representa mi primera página web desarrollada utilizando HTML y CSS.

El objetivo fue aprender y poner en práctica los fundamentos del desarrollo web, creando una página con estructura organizada, estilos personalizados y una interfaz visual.

### Tecnologías utilizadas

- **HTML:** Estructura y contenido de la página.
- **CSS:** Diseño, estilos, colores y distribución de los elementos.

### Objetivos de aprendizaje

- Comprender la estructura básica de HTML.
- Aplicar estilos mediante CSS.
- Organizar elementos dentro de una página web.
- Practicar la creación de interfaces visuales.
- Dar mis primeros pasos en el desarrollo frontend.

### Demo del proyecto

[Ver página web](https://remarkable-buttercream-1f470d.netlify.app/)

### Aprendizaje

Este proyecto es uno de mis primeros pasos en el desarrollo web y representa el inicio de mi aprendizaje en la creación de interfaces utilizando tecnologías frontend.
